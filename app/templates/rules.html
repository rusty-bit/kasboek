You don't need rules for most things: when you pick a category, Kasboek already remembers that shop (and other branches of the same chain, and the same IBAN). A rule is for names that vary, for example "every name containing tikkie", or for amount or direction conditions. A rule never changes a category you set by hand. All conditions must hold. When two rules match, the newest one wins.
