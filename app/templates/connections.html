Alerts on your phone (ntfy)

Kasboek sends each new alert once: a price going up, a contract deadline, a low balance ahead, a budget you went over, a bank permission running out. It checks every hour and after each bank sync. Install the ntfy app, run an ntfy server in your home (for example as a container on the NAS) and subscribe to a topic. Kasboek only sends to an address on your own network, so the texts with your amounts stay at home.

Home Assistant

Home Assistant can show free to spend, the lowest balance ahead, your pots and the alerts. It reads {{ base }}/api/summary with a token. The token only opens that address, not the rest of Kasboek.

In Home Assistant's configuration.yaml:

rest:
  - resource: {{ base }}/api/summary
    headers:
      Authorization: "Bearer {{ token if token else '<your token>'|safe }}"
    scan_interval: 900
    sensor:
{%- raw %}
      - name: "Kasboek free to spend"
        value_template: "{{ value_json.free_to_spend }}"
        unit_of_measurement: "€"
      - name: "Kasboek per day"
        value_template: "{{ value_json.per_day }}"
        unit_of_measurement: "€"
      - name: "Kasboek lowest balance 90 days"
        value_template: "{{ value_json.lowest_balance_90d }}"
        unit_of_measurement: "€"
        json_attributes:
          - lowest_date
      - name: "Kasboek alerts"
